# 🩸 Blood Donor

Blood Donor is a Flutter application designed to display a list of people who may be able to donate blood. The project was created as a learning project while exploring Flutter app development.

## ✨ Current Features

- Display a list of people's names.
- Simple user interface built with Flutter.

## 🛠️ Technologies Used

- Flutter
- Dart

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd blood_donor
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## 📌 Project Status

This project is currently in its initial stage. It displays people's names and may be extended with features such as blood group information, blood donation requests, and donor registration.

## 🎯 Learning Objective

The goal of this project is to practise Flutter development and gradually improve the application by implementing useful features.
